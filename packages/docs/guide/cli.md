> 环境要求: 要求 node18.x 版本以上

## 1. 安装

安装脚手架

```bash
npm install -g @freelog-cli/core

```

## 2. 创建项目

新建项目文件夹，在文件夹下打开命令窗口

执行命令`freelog-cli init`后,使用上下箭头选择项目类型：主题、插件、软件库

输入项目名称，版本号，nameSpace(软件库独有，具体信息请参考[库开发者](../library/guide))

```bash
freelog-cli init
```

## 3. 启动项目

```bash
npm run start
```
