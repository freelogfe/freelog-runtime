# 首次签到节点

::: info CLI 同步文档
本页自动同步自 CLI 仓库使用手册。先核对已安装版本与本页适用范围；Node.js 22.14+ 是 CLI 自身要求，不是运行时对子应用的要求。来源、发布状态及已知限制见[版本说明](/about)。
:::


适用于尚未创建目标展品、希望把线上资源或合集接入本人节点的情况。市场查询、节点选择、创建参数和后续管理看[节点与展品](../节点与展品/index.md)。

1. 确认本人节点、来源资源或合集、版本及策略。合同被授权方是节点，不能以个人合同或作者资源的依赖合同代替。
2. 按[节点与展品手册的签到步骤](../节点与展品/index.md#_2-签约成展品)补全创建参数，查看来源策略和条款，再明确选择并确认；`--yes`不代选策略，也不能默认使用第一条策略。
3. 遇到必要上抛或需要复用已有节点合同等不支持的情况，到对应环境的Console打开来源资源详情的“签约到节点”，选择正确节点并核对策略、条款和已有合同。不能省略必要上游或重复签约来绕过限制。
4. 创建后查询并核对展品ID、所属节点、来源、版本及合同；在网页创建的展品也先查到实际结果。需要支付或其他履约时，进入所属节点的该展品编辑页，在“资源授权”核对正确合同后由本人办理，见[支付与恢复](./支付与恢复.md)。
5. 回到该展品，用[整体授权检查](../节点与展品/index.md#上架前检查整体授权)核对当前结果，再继续资料、配置、面向访问者的销售策略及上架。创建成功不自动上架，也不代表内容可访问。

同节点已有同源展品时先查询，不重复创建。给已有展品签另一策略或管理合同，进入[展品资源授权](./展品资源授权.md)。创建结果未知时保留操作ID并按节点教程恢复，不能再次发送创建。
