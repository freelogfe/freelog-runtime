# 首次签到节点

::: info CLI 同步文档
本页自动同步自 CLI 仓库使用手册。先核对已安装版本与本页适用范围；Node.js 22.14+ 是 CLI 自身要求，不是运行时对子应用的要求。来源、发布状态及已知限制见[版本说明](/about)。
:::


策略选择界面可用空格勾选多条、回车确认；选择界面仅显示名称和 ID，提交确认页展示所选条款。

适用于尚未创建目标展品、希望把线上资源或合集接入本人节点的情况。市场查询、节点选择、创建参数和后续管理看[节点与展品](../节点与展品/index.md)。

1. 选择节点、来源资源或合集、版本及策略。节点权限由后端按登录token判断。
2. 执行 `exhibit add` 后依次选择节点、填写展品标题、填写授权标识并查重、选择策略、查看完整条款并确认。交互模式未传 `--sign-policy` 时会提示选择至少一条启用策略；已经通过参数提供的字段不重复询问。非交互模式须明确提供策略，`--yes` 不代选策略。省略 `--version` 使用最新已发行版本，作者合集固定1.0.0；也可以用该参数明确指定已发行版本。确认摘要展示本次精确版本，之后新发版本不会改变本次提交。

   命令行指定多个策略时，重复传入 --sign-policy <来源资源ID=策略ID>，例如：exhibit add <来源资源ID> --node <节点ID> --name <授权标识> --sign-policy <来源资源ID>=<策略ID一> --sign-policy <来源资源ID>=<策略ID二> --yes。两条策略会一同提交；重复策略 ID 会在创建前拒绝。
3. 遇必要上游、合同复用等当前包未支持情况，按指引到Console办理，不省略上游或退回旧实现自动签约。
4. 成功响应直接返回展品ID，创建到此完成；可用展品查询命令查看实际节点、来源、版本及合同。需要支付或其他履约时，到正确节点合同下办理，见[支付与恢复](./支付与恢复.md)。
5. 返回展品继续资料、配置、面向访问者的销售策略及上架。创建成功不自动上架，也不代表内容可访问。

同节点已有同源展品时先查询，不重复创建。给已有展品签另一策略或管理合同，进入[展品资源授权](./展品资源授权.md)。创建结果不确定时CLI直接返回错误，不保存操作记录或提供此创建动作的恢复；可查询节点展品了解当前结果。后端负责判断重复请求及权限。
