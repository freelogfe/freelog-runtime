# 已有展品的资源授权

::: info CLI 同步文档
本页自动同步自 CLI 仓库使用手册。先核对已安装版本与本页适用范围；Node.js 22.14+ 是 CLI 自身要求，不是运行时对子应用的要求。来源、发布状态及已知限制见[版本说明](/about)。
:::


对应普通展品或合集展品详情中的“资源授权”：查看来源合同与授权状态、支付或其他履约、应用/搁置合同及需要时签新策略。不是再次创建展品，也不是编辑展品自己的销售策略。

合同被授权方仍是**展品所属节点**，当前展品是合同应用的上下文。先核节点、展品、来源及实际版本，不能把展品ID当节点ID或用个人合同代替。

1. 按[已有展品的资源授权](../节点与展品/index.md#_8-已有展品的资源授权)查询来源授权、合同及应用状态，区分已有合同与当前展品实际使用的合同。
2. 对已有精确合同，按教程显式应用或搁置并读回确认；多份或冲突时按提示处理，不能任取第一份。
3. 需要签另一条策略或没有可复用合同时，到对应环境的Console进入**所属节点的该展品编辑页**，在“资源授权”查看条款并明确选择策略后办理。CLI目前不为已有展品新建合同；不要再次创建展品来补签。
4. 需要支付或其他履约时，由本人核正确节点合同并办理，见[支付与恢复](./支付与恢复.md)。
5. 网页办理后，回CLI重新查询合同，按需要应用，再执行[整体授权检查](../节点与展品/index.md#上架前检查整体授权)。核对当前结果后，返回原展品继续上架或使用；这些授权操作不会自动改资料、换版本或上架。

合同操作可能影响授权范围，以实际预览和回读为准，不把当前展品状态套用到其他展品。未知操作先保留并只读核实，确认后按原恢复入口收尾，不手工清日志重发。
