# 环境、登录与凭据

::: info CLI 同步文档
本页自动同步自 CLI 仓库使用手册。先核对已安装版本与本页适用范围；Node.js 22.14+ 是 CLI 自身要求，不是运行时对子应用的要求。来源、发布状态及已知限制见[版本说明](/about)。
:::


账号选择与资源选择是两件事：登录决定以谁的身份请求平台；`--resource` 决定操作哪个资源或合集。两者都要与工程、环境一致。

## 环境

| 环境 | 当前状态 |
|---|---|
| `--env dev` | 开发联调可用。 |
| `--env test` | 测试联调可用。 |
| `--env prod` | 当前 CLI 拦截平台调用。 |

优先级：命令行 `--env` → 环境变量 `FREELOG_ENV` → `prod`。教程每条示例显式带 `--env dev`；切换时同时检查身份记录和凭据环境，不复制 dev 身份去当 test 资源。

## 人工登录与切换

```powershell
freelog-cli login --cwd <工程目录> --env dev
```

在交互终端输入账号与密码。密码以星号反馈，输完按Enter提交；随后显示当前环境的登录等待提示，最多等待15秒。已有正确登录不必重登；需要切换账号或环境时，先退出原登录，再登录目标环境。

平台明确拒绝登录或发送验证码时，CLI显示后端返回的可安全展示的原因；例如未绑定联系方式时改用密码登录。网络超时或响应无法核实时另行说明，不保存不完整登录态、不自动重发验证码。错误分类见[故障恢复](./09-常见情况与报错.md#先看失败原因-再决定下一步)。

账号输入错误时，可以在按Enter前用退格修改。

在账号或密码问句中按Ctrl+C取消，不发送登录请求、不保存凭据。Windows密码输入取消仍有进程未退出的已知场景；请确认命令已回到终端提示符，必要时关闭这次登录窗口，不把等待超时当成正常退出。取消提示不表示提交了资源操作。

```powershell
freelog-cli logout --cwd <选择器所在目录> --env dev
freelog-cli login --cwd <选择器所在目录> --env test
```

`logout` 不删除资源身份、版本工作稿或线上资源。登录请求默认 15 秒超时；网络、认证或系统凭据库报错时，不继续创建登录选择器。

身份或凭据格式异常时，CLI会在保存前拒绝。安全的后端失败原因会展示；完整认证响应、秘密和调用堆栈不直接输出。检查账号、环境后按提示处理，不手工补写选择器。超时后迟到的响应不继续保存登录态，也不自动重试请求。

若提示 `LOGIN_SELECTOR_SAVE_UNCONFIRMED`，系统库已保存，但选择器写盘未确认，文件可能已存在。先核对报错路径：存在则在该目标 `logout`（机器默认用 `--global`）；处理权限／空间问题后重新 `login`。不要手动删除系统凭据：同环境同用户的其它工程可能共用它，且可能已读到这次刷新的凭据；工程身份和工作稿会保留。

## 手机验证码登录

需要用手机验证码登录时，在你自己的交互终端运行：

```powershell
freelog-cli login --method code --env dev
```

1. 输入手机号，也可输入平台已绑定手机/邮箱的账号或邮箱。CLI先检查格式与注册状态：错误手机号提示格式有误，合法但未注册的输入提示找不到账号；此时不取图、不发码。纯数字用户名会先核实，真实存在的数字用户名仍可登录。查询失败会明确提示无法核对，不当作未注册。
2. CLI默认输出“验证码图片：”后的白底PNG绝对路径，不自动打开浏览器。Agent代办时，应在命令等待输入期间读取这个PNG，用图片展示工具直接显示在对话里；只打印路径不算完成展示。人工可自行打开PNG，或在命令中加`--open-captcha`自动打开浏览器展示。看图后在同一终端输入图中字符，不把答案发到聊天里。
3. 图形验证通过后，CLI发送验证码，提示后端返回的脱敏收件地址；输入收到的六位验证码，输入显示星号，按Enter提交。
4. 看到“登录成功”后，AI即可继续使用当前工程的登录态操作。

可加`--login-name <手机号或账号>`免去第一项问答；要保存机器默认账号再加`--global`。先确认目标目录及环境，已有目标登录请先按下文退出，不会覆盖。

人工需要自动打开浏览器时使用：

```powershell
freelog-cli login --method code --open-captcha --env dev
```

`--open-captcha`仅用于验证码登录；密码登录不能使用。两种展示方式都保留PNG路径。图形码错误不会发短信。一次命令只发一次验证码、提交一次登录，失败不自动重发；超时、验证码错误或过期时按提示稍后重新运行，频率以平台限制为准。在任一步按Ctrl+C可取消；结束时清理临时PNG及可选展示页。显式打开浏览器失败不会影响后续输入，可自行打开PNG查看。

此方式的验证码必须由真人在交互终端输入，不能加`--yes`、`--json`或`--password-stdin`。让AI启动流程并展示图片后，由你在同一终端输入，不把验证码、密码或token发到聊天或写进文件。工具不能提供可输入的终端时，使用你自己的终端登录，再让AI复用该工程登录态。

微信登录需要后端配置及CLI扫码结果交接支持，本期尚未实现；不要把网页登录二维码当作CLI登录入口。

## 目录继承与全局默认

命令从 `--cwd`（未传时当前目录）向上查找最近的 `.freelog/auth`。例如已在父目录登录，`--cwd my-theme` 可以继承父目录账号；如果要为该工程单独选择账号，在工程内 login。

找到了最近的选择器，却损坏、凭据缺失或环境不一致时，命令停止，**不会跳过它使用父目录或全局账号**。退出继承的账号时应明确使用实际选择器所在目录。

需要机器默认账号时登录：

```powershell
freelog-cli login --global --env dev
```

之后确实需要清除机器默认账号时再执行，不是登录后的下一步：

```powershell
freelog-cli logout --global --env dev
```

全局默认只有在目录向上没有工作区选择器时才生效。

## AI、脚本与 CI

非交互登录同时提供账号、保密标准输入和确认：

```powershell
freelog-cli login --login-name <账号名> --password-stdin --yes --cwd <工程目录> --env dev
```

这不是可直接复制执行的完整密码输入流程：调用方须通过受保护的标准输入供应密码。不要将真实密码写进命令行、示例、脚本、JSON、日志或 Git；也不要以明文环境变量作为教程中的传递方式。CLI 没有公开 `--password` 参数。

## 凭据存放与安全

| 内容 | 存放位置 | 可提交 Git |
|---|---|---|
| 工作区账号选择器 | `.freelog/auth` | 否。 |
| 机器默认选择器 | 用户目录的 `.freelog/auth-default.json` | 否。 |
| token、Cookie 等登录秘密 | 操作系统凭据库 | 不作为工程文件。 |

选择器只保存环境、用户 ID、账号名、schema 与凭据库 key，不保存密码、token 或 Cookie。复制它到另一台机器不能移植登录态，另一台机器需重新 login。

不要手工修改选择器中的环境、用户 ID 或凭据键。三者必须精确对应；不一致时 CLI 按损坏选择器拒绝，既不读取其引用的系统凭据，也不换用全局账号。遇到损坏、凭据缺失或不可用的登录态，按上面的退出／登录流程处理目标工程（全局默认则使用 `--global`），不要复制或拼接另一账号的字段。

含旧 token/cookie/iv 的文件不自动解密或迁移，明确 logout 后重新登录。认证失败时停止操作；已有未提交工作内容不因退出登录而清除。其它状态与恢复边界见[本地文件参考](./10-本地文件参考.md)和[故障恢复](./09-常见情况与报错.md)。
