## 发现命令与获得帮助

`freelog-cli --help`列出顶层命令及安装包内手册的绝对路径；`--cli-version`打印CLI自身版本。业务组本身用于查看子命令，执行具体操作使用下表的完整命令路径。

`init`、`collection publish`和`version attr review`既有子命令，也可按各自表格独立执行。分组未单独列操作行不表示其子命令不可用。

`node list`在本页“节点列表、资料与设置”表中有独立条目，不使用作者资源选择器：

`freelog-cli node list --env dev`

查询具体命令参数时使用：

`freelog-cli node list --help`、`freelog-cli version dep add --help`、`freelog-cli exhibit add --help`。

## 共用参数

| 参数 | 当前含义与边界 |
|---|---|
| `--env <env>` | dev/test；prod平台读取和写入当前均拦截。优先级为命令行、FREELOG_ENV、prod默认值，示例显式dev。 |
| `--cwd <dir>` | 工作目录及登录上下文，不代替节点/展品ID；含空格的路径按shell规则加引号。 |
| `--json` | 使用该命令支持的机器结果；共用失败出口为code/message/category/outcome，包含参数解析失败。成功数据仍按各命令分别定义，见下方成功输出。 |
| `--yes` | 跳过允许跳过的确认，不绕过校验、登录、合同或未决保护；节点创建/删除仍需专用确认。 |
| `--resource <selector>` | 选择作者单资源/合集身份；适用范围见下一节。不是用于选市场资源、节点或展品。 |
| `-h, --help` | 查看该命令帮助，不执行业务。 |

共享参数只在适用命令的帮助中展示。节点、展品、市场、存储和支付不接受作者`--resource`，误传会明确拒绝；作者合集create/bind同样拒绝。登录/类型等命令不靠此参数选择作者业务目标。

`--env`、`--cwd`、`--resource`出现时必须有值，不能将后续选项当值。缺值或未知选项是参数解析错误：退出2；传了独立的`--json`时，stdout只有一份错误JSON，category=input、outcome=error。未启用JSON时给出文字错误；`--`之后或选项等号值里的`--json`不启用机器模式。详见[错误输出与退出码](./09-常见情况与报错.md#参数解析错误和-json-输出)。

## 公共资源匹配参数

一个目录可有多个视频、图片或其它资源；用户不需要记住 `.freelog/2.json`。对任何常规单资源命令使用同一个参数：

```text
--resource id:<资源ID>                 # 最稳定，推荐
--resource name:<username/name>         # 完整不可变标识，推荐
--resource artifact:<相对文件或目录>    # 例如 artifact:video.mp4
--resource file:N.json                 # AI、脚本、恢复时的精确状态文件
```

`--resource artifact:video.mp4` 是**选择**已记录为 `video.mp4` 的资源；发行命令中的 `--artifact video-v2.mp4` 才是本次上传新文件。二者可以同时出现。单份状态自动选择；多份状态在 TTY 展示标题、标识符、ID、产物和工作稿供选择，非交互则列出上述可复制候选并停止。标题重复时使用 `id:`、`name:`、`artifact:` 或 `file:`。

产物输入接受工程内绝对或相对路径；确认后统一记录为相对工程根的路径。`artifact:`选择器同样支持这两种写法，不能因此选择工程外产物。`init [dir]`以最终项目目录为根；路径中有空格时按当前shell规则加引号。缓存里的filePath仍须是相对路径，不要手工写入绝对路径。

### AI与脚本读取成功结果

以下命令支持结构化成功输出。`--json`本身不保证所有命令都实现成功JSON；表中说明与各业务教程共同定义当前结果。

| 命令 | 可读取的数据 |
|---|---|
| `type list/search` | 全部匹配叶子数组，code/name/nameChain包含完整祖先；空结果为[]，不在JSON中分页。 |
| `type info`、`type pick --type <code>` | 类型详情，supportsOptionalConfig为是否支持配置的布尔值。JSON pick须明确type。 |
| `template list` | 脚手架模板数组，包含id/npmName/version/name/targets；与策略模板不同。 |
| `create` | resourceId/name/typeCode；name是创建时的短标识，只代表壳已创建，后续优先用resourceId选择资源。 |
| `resource show [资源ID或username/name]` | 本人线上资源资料，包括intro、标签、封面、状态及最新版本；无位置目标则按本地--resource选择。壳、下架和冻结资源也可查，不同步本地缓存。 |
| `exhibit authorization check <展品ID>` | 所属节点及资源侧整体授权，读取isAuth；false仍是成功查询，不能只看exit0认定已授权。 |
| `create-version/update-version` | resourceId/outcome/version/draftRetained。outcome为prepared、published或cancelled，只有published的version是已提交版本号；draftRetained=true时保留本地稿，不要重复提交同一版本。 |
| `version attr list` | customAttributes、systemAttributes及definitionsAvailable。附加属性按当前类型定义读取，未填写value=null，显式清空为""；无已准备文件时不编造字段，不把定义可用当作文件解析完成。 |
| `version option add/set/rm` | key/saved/published/draftFile/draftCreated。saved=true、published=false代表只保存了本地工作稿；JSON写入必须--yes。 |
| `version option list` | 当前稿的配置描述符数组，空结果为[]。 |
| `version dep list`、`collection dep list` | 依赖声明数组，附`authorization:{contractNames,authorization,freshness,observedAt?}`本地摘要；不自动查询授权。 |
| `version dep refresh [resourceId]`、`collection dep refresh [resourceId]` | 当前稿全部或单项授权摘要刷新结果；失败非零且只返回一份JSON，缺提供者为unavailable，不等于无合约。 |

本表命令成功时stdout只有一份JSON，文字提示不混入其中；失败通过共用出口返回code/message/category/outcome。具名批量结果保留原明细并追加共同字段，不能只看部分成功项就继续写入。退出码分类见[错误说明](./09-常见情况与报错.md#参数解析错误和-json-输出)。多份本地身份时，JSON查询及版本/配置操作明确传`--resource`，不会弹出选择菜单。JSON重置版本稿须同时`--reset --yes`，缺少确认会拒绝，不能以JSON模式绕过有损操作确认。

例如先查询，再根据返回字段决定后续步骤：

```powershell
freelog-cli type search 图片 --json --env dev
freelog-cli version dep list --resource id:<资源ID> --json --env dev
```

`version dep rm <依赖ID> --json`成功返回`{ "resourceId": "<依赖ID>", "removed": true, "saved": true, "published": false }`，只删除本地稿中的声明，不撤销合同。合集的相同返回及目录查询见[合集教程](./合集/02-发行后管理与边界.md#直接依赖与依赖版本)。其它命令是否支持成功JSON，仍查看对应说明；共用`--json`参数本身不是全命令成功协议的承诺。

## 账号、工程和类型

登录保存账号凭据；初始化只准备本地身份和产物，不自动创建线上资源。详情见[环境与凭据](./02-环境与凭据.md)、[主题与插件](./05-主题与插件.md)。

| 命令与专用参数 | 作用与限制 |
|---|---|
| `login [--global] [--login-name <name>] [--password-stdin] [--open-captcha] [--method <method>]` | 默认method=password；code在取图前检查格式及注册状态，保留真实数字用户名，查询失败不当作未注册。通过后进行图形码及手机/邮箱验证码。默认输出白底PNG路径，Agent在对话中展示；仅code可用--open-captcha打开浏览器。code必须真人TTY，不与yes/json/password-stdin合用。密码stdin须同时给login-name和yes。global选择机器默认账号，否则写当前工程选择器。微信登录未提供。 |
| `logout [--global]` | 退出最近工作区账号；global明确退出机器默认账号。不删除资源身份、工作稿或线上资源。 |
| `init [dir] [--type <leaf-code>] [--storage-object <id>] [--artifact <path>]` | 建立首份未绑定N.json。明确本地artifact或本人storage-object，二者互斥；普通资源type须最终叶子。非交互须明确dir与type；当前目录写“.”。不覆盖既有状态，不上传、不发行。 |
| `init theme [dir] [--template <id>]` | 安装线上主题模板，固定RT001，默认产物dist。脚本明确dir、template及yes；目标须满足空目录规则。 |
| `init widget [dir] [--template <id>]` | 安装线上插件模板，固定RT002，默认产物dist。脚本明确dir、template及yes；不覆盖已有项目。 |
| `template list` | 只读脚手架模板列表，包含主题/插件适用范围；不同于授权策略模板。 |
| `type list` | 查询可用最终叶子及完整祖先路径。TTY固定每页50条，可翻页；非TTY显示首页及提示；JSON返回全部匹配项。 |
| `type search [keyword]` | 按关键词查询最终叶子；显示完整祖先路径，分页与type list相同。 |
| `type pick [--type <code>]` | 交互选择最终叶子，或用type明确指定；非交互/JSON必须给type。 |
| `type info [type]` | 查询类型详情、完整名称链及supportsOptionalConfig；脚本明确给type。配置能力以此结果为准。 |

## 建立或接入资源身份

以下为作者单资源操作。多身份时使用--resource；位置目标与选择器的具体组合见[日常路径](./04-日常路径.md)。

| 命令与专用参数 | 作用与限制 |
|---|---|
| `create [--title <title>] [--type <type>] [--name <name>] [--storage-object <id>] [--artifact <path>]` | 创建本人线上资源壳并记录resourceId；title为可变标题，name为不可变短标识。可接续未绑定身份。artifact与storage-object互斥，仅关联产物，不上传、发行或上架。 |
| `bind <target> [--force] [--storage-object <id>] [--artifact <path>]` | 接入本人的线上单资源，target用精确ID或username/name。force配合yes才允许替换明确选择的身份；可能丢弃其原稿，需先核对。 |
| `status` | 只读当前本地身份、稿状态与线上latest，不等于查看资源完整资料或上下架状态。 |
| `resource list` | 只读诊断本工程身份、单资源工作稿及未决记录；不是“我的线上资源”列表，不自动修复。 |
| `resource show [resourceIdOrName]` | 查看本人线上资源资料；位置目标与resource互斥，省略位置目标按本地身份选择。未发行、下架或冻结也可查；不bind、不改缓存。 |
| `resource sync` | 刷新绑定身份的本地标题；无选择器同步当前环境全部已绑定单资源，否则只同步所选一份。部分失败返回批次结果且退出非零。 |
| `resource recover [--apply]` | 默认只读核验版本未决操作，不重发；apply与yes显式收尾。确认成功后仅删摘要未变的稿，变稿保留；未发送记录只清记录留稿。 |

## 版本：查看、工作稿与提交

只用于作者单资源。首版固定1.0.0，之后显式新号或bump；准备稿成功不等于线上发行成功。详情见[版本工作稿](./06-版本工作稿.md)。

| 命令与专用参数 | 作用与限制 |
|---|---|
| `version show [--version <ver>] [--local]` | 查看指定已发行版本；未给版本时TTY可选择，非交互/yes用latest。local只读当前未提交稿，不拉取或覆盖。 |
| `version set [--artifact <path>] [--storage-object <id>]` | 只修改身份默认产物来源：工程内文件/构建目录或本人存储对象，二者互斥。不上传、不提交。 |
| `version draft pull [--version <ver>]` | 拉取latest或指定已发版本为更新稿；覆盖已有稿须确认，脚本用yes明确同意丢弃原稿。 |
| `version draft discard` | 明确放弃并删除选中的版本稿；交互默认不删，脚本须yes。不删除线上版本。 |
| `version draft import-storage <objectId> --groups <groups>` | 按groups显式导入attributes、options、dependencies，可逗号组合。依赖按资源ID合并并更新范围；属性先按当前类型转换；所选属性/配置组替换，未选组保留。不换文件来源、不发行。 |
| `version draft description [--description <text>]` | 只修改未提交稿的版本说明；非交互明确给description。 |
| `version description [--version <ver>] [--description <text>]` | 修改已发行版本的说明；省略版本时非交互用latest，TTY可选择。description空串清空，不创建新版本，不修改工作稿。 |
| `create-version [--prepare] [--reset] [--artifact <path>] [--storage-object <id>]` | 仅首版：prepare准备文件、校验字段定义并保存稿，不等只读属性解析、不提交；不带prepare则提交1.0.0。reset须明确放弃原稿；artifact与storage-object互斥。成功只清本次未变稿，未知用resource recover。 |
| `update-version [--reuse-version <ver>] [--version <ver>] [--bump <level>] [--reset] [--artifact <path>] [--storage-object <id>]` | 已有版本后发新版：version与bump二选一，bump为patch/minor/major。reuse-version明确旧底稿；reset明确放弃当前稿。产物来源二选一；成功只清未变稿，未知用resource recover。 |

## 版本属性、可选配置与依赖

以下只编辑或查看当前单资源工作稿；已有版本先pull，首版先create-version --prepare。一行式输入与JSON形状见[版本工作稿](./06-版本工作稿.md)。

| 命令与专用参数 | 作用与限制 |
|---|---|
| `version attr add [line]` | 新增自定义属性。一行式例如“名称=作者 键=author 值=张三”；完整输入加yes可跳确认。 |
| `version attr set [line]` | 修改已有属性；系统附加字段按当前类型规则填写，不允许伪造系统键。 |
| `version attr rm <key>` | 只移除本地稿中的自定义属性，不修改已发行版本。 |
| `version attr list` | 查看自定义及系统附加属性、字段定义可用情况；缺值不编造为已填写。 |
| `version attr review` | 只读查看类型字段定义变化后的待复核系统附加属性；未处理的待复核项阻止提交。 |
| `version attr review discard <key>` | 确认丢弃一项待复核系统附加属性；不把它当作已通过校验。 |
| `version option add [line]` | 资源类型支持时新增可选配置。示例“名称=主题 键=theme 方式=文本 默认=dark”；最终键按配置规则保存。 |
| `version option set [line]` | 修改已有配置；类型能力、键、默认值及选项均校验，不修改线上版本。 |
| `version option rm <key>` | 删除稿中配置，也可清理已不支持配置类型的遗留项。 |
| `version option list` | 只读配置描述符列表；JSON空结果为[]。 |
| `version dep add <resourceId> [--range <range>]` | 声明直接依赖，resourceId也接受完整资源标识。可先存未签依赖；来源作者合集范围固定1.0.0。已有声明未给range时保留范围，不查合同、不签约。 |
| `version dep range <resourceId> [--range <range>]` | 只改已声明依赖范围；TTY可选已发版本及固定/兼容/自定义范围，非交互明确range。作者合集来源仍固定1.0.0。 |
| `version dep rm <resourceId>` | 只删除工作稿中的声明，不撤销合同或删除来源资源。 |
| `version dep list` | 只读声明、版本范围及已保存的授权摘要，不自动重新查询授权。 |
| `version dep refresh [resourceId]` | 尝试刷新全部或单项声明的授权摘要；查询暂不可用时返回unavailable，不表示无合同或未授权。 |
| `version dep sign <resourceId> [--policy <policyId>]` | 只读核正确资源主体已有合同；缺合同时返回浏览器指引，不签新合同、不支付、不修改依赖稿。 |
| `version dep recover [operationId] [--apply]` | 只读核依赖操作未决记录；apply与yes精确收尾，始终保留当前稿，不重发签约。 |

依赖声明、签约和访问授权分别核对。当前依赖授权新链未开放，签约/支付到浏览器办理；正式发行仍校验正确资源主体的适用合同，已签未支付不等于已获访问授权。

## 展示信息、策略与上下架

## 作者合集：目录、直接依赖与收录规则

目录单品维护的是服务端目录草稿；直接依赖维护的是本地表单稿，二者不要混用。下方收录规则立即按对应接口更新，不等于已发布目录。

| 命令与专用参数 | 作用与限制 |
|---|---|
| `collection item list [--search <text>]` | 查看服务端目录草稿，可按search筛选；JSON返回单品数组。 |
| `collection item add [source...] [--sign-policy <mapping>]` | 加入本人线上已上架单资源；source可多项，省略时TTY线上选择。sign-policy可重复“资源ID=策略ID”，只匹配必要上抛已有合同，不签新合同；部分失败须核结果分区。 |
| `collection item rename <item-id> --title <text>` | 按目录item-id修改草稿单品标题，不改来源资源标题。 |
| `collection item remove <item-id...>` | 按一个或多个item-id移除目录草稿条目，不删来源资源或合同。 |
| `collection item move <item-id> [--before <item-id>] [--after <item-id>]` | 将草稿单品移到另一条之前或之后；before/after二选一。 |
| `collection item sort --by <field> [--asc] [--desc]` | 按by字段整体排序草稿，asc/desc二选一；具体字段见合集手册。 |
| `collection item auth status <item-id...>` | 查询指定单品及其必要上游的已有合同/授权，不将个人授权当合集授权。 |
| `collection item auth resolve <item-id> [--sign-policy <mapping>]` | 核验并应用指定单品必要上游的已有合同，可能修改服务端目录草稿的合同应用映射；sign-policy明确匹配，缺合同引导浏览器。不签新合同、不支付、不发布目录。 |
| `collection dep add <source> [--range <range>]` | 向本地表单声明直接依赖，单资源范围显式校验，作者合集来源固定1.0.0；允许未签先存稿，不执行授权操作。 |
| `collection dep range <source> [--range <range>]` | 修改已有直接依赖的版本范围；不查合同，不签约，不发布表单。 |
| `collection dep rm <resource-id>` | 从本地表单移除直接依赖声明，不撤销合同。 |
| `collection dep list` | 只读本地直接依赖及授权摘要，不自动查询授权。 |
| `collection dep refresh [resourceId]` | 尝试刷新全部或单项直接依赖授权摘要；当前提供方未接入时unavailable，不等于无合同。 |
| `collection dep sign <source> [--policy <policyId>]` | 只读核已有合集主体合同；缺合同指引浏览器，不签约/支付，不改稿。 |
| `collection dep recover [operation-id] [--apply]` | 默认只读核依赖未决记录；apply与yes才精确收尾，当前表单稿保留。 |
| `collection collect-rules get` | 只读连载状态与自动收录规则。 |
| `collection collect-rules set [--serialize <state>] [--auto <mode>] [--rules <path>]` | 仅修改显式字段。serialize为completed/serial；auto为off/all/any，开启需rules JSON。完结关闭自动收录、保留条件；恢复连载不自动开启。 |

## 展品：来源授权与消费策略

来源授权决定节点能否使用资源；消费策略决定访问者如何使用展品。两者分开。签约和付款细节由[授权与支付](./授权与支付/index.md)维护；主CLI不重复实现授权工作流。

| 命令与专用参数 | 作用与限制 |
|---|---|
| `exhibit authorization check <exhibitId>` | 只读检查整体授权。isAuth=false仍可代表查询成功，不是已授权。 |
| `exhibit authorization list <exhibitId>` | 只读来源资源及必要上游的合同、授权和应用情况；不新签或付款。 |
| `exhibit authorization sign <exhibitId> --resource-id <sourceId> --policy <policyId> --scope <scope> [--apply]` | 当前仅核对正确节点主体的已有适用合同，缺合同时引导浏览器。resource-id、policy、scope=node必填；apply明确应用已有合同。不创建新合同或支付。 |
| `exhibit authorization apply <exhibitId> --contract <contractId>` | 显式应用该节点已有来源合同，contract必填；不能把个人合同用于节点。 |
| `exhibit authorization shelve <exhibitId> --contract <contractId>` | 显式搁置该节点已有合同应用，contract必填；不解除或删除合同。 |

| `exhibit policy set <exhibitId> --policy-id <id> [--on] [--off]` | policy-id必填，on/off二选一；校验上下架约束后启用/停用消费策略。 |
| `exhibit policy template list <exhibitId>` | 查看消费策略模板；TTY每页50可选模板、编辑参数、预览确认，JSON只读。与作者模板20条分页不同。 |
| `exhibit policy template apply <exhibitId> <templateId> --name <name> --fingerprint <fingerprint> [--param <slot=value>]` | 明确exhibitId及templateId，必填name、fingerprint，param逐槽传完整值，脚本另加yes。这里是fingerprint，不是作者命令的template-fingerprint。收费先核节点结算资格；不代添加结算方式。 |

| 命令与专用参数 | 作用与限制 |
|---|---|
| `exhibit collection type list` | 只读节点自建展品合集可用类型树，包含children；创建时必须选可用最终叶子，不能直接选父级。 |
| `exhibit collection create [--node <id>] [--title <text>] [--name <text>] [--type <code>]` | 创建本节点的自建展品合集，给定node/title/name/type；不自动添加成员、策略或上架。 |
| `exhibit collection list [--node <id>] [--page <n>]` | 查询本人节点的自建展品合集，按page分页；不是作者合集列表。 |
| `exhibit collection show <collectionId>` | 只读指定自建展品合集详情。 |
| `exhibit collection item list <collectionId> [--page <n>] [--keywords <text>]` | 查看成员，可按keywords筛选、page分页，并观察授权；不展开签约策略。 |
| `exhibit collection item add <collectionId> --exhibit <id>` | exhibit可重复，1至100个本节点普通展品；只收录成员，不签资源或复制展品。部分失败返回分区且退出非零。 |
| `exhibit collection item remove <collectionId> --item <id>` | item可重复，按本合集itemId解除收录；不删展品、资源或合同。 |
| `exhibit collection sort move <collectionId> --item <id> --position <n>` | item可重复，作为一块移动至position（1至成员总数），块内保留原目录顺序。 |
| `exhibit collection sort quick <collectionId> --by <field> [--descending]` | by为added/title/released；descending倒序，省略时标题升序、时间降序。 |
| `exhibit collection sort direction <collectionId> [--ascending] [--descending]` | ascending/descending二选一，只改展示方向，不改成员实际排序。 |
| `exhibit collection auto show <collectionId>` | 只读当前自动收录条件及启停状态。 |
| `exhibit collection auto set <collectionId> --file <path>` | file为conditionType/filterConditions完整JSON；保存并开启规则，只收录未来新签入的匹配普通展品，不回扫或移除旧成员。 |
| `exhibit collection auto on <collectionId>` | 开启已配置规则，保留条件和当前成员；不是立即批量补收录。 |
| `exhibit collection auto off <collectionId>` | 关闭规则，保留条件及已有成员。 |

自建展品合集的标题、简介、封面和标签用`exhibit update`；消费策略用`exhibit policy list`、`exhibit policy set`、`exhibit policy template list/apply`；上下架用`exhibit online/offline`；未知结果用`exhibit recover`。不需要创建作者资源壳或发行资源版本。

## 支付与历史查询

当前新支付统一去浏览器，CLI不创建新订单或二维码。这里列出仍注册的指引与只读入口，不能把列有参数理解为已开放支付。具体操作见[支付与恢复](./授权与支付/支付与恢复.md)。

| 命令与专用参数 | 作用与限制 |
|---|---|
| `payment show <contractId>` | 只读本人合同的支付事件、原价及渠道。 |
| `payment status <orderId> [--wait]` | 只读原订单及合同；wait最多等待五分钟，不重付或续期。 |
| `payment start <contractId> [--event <id>] [--method <method>] [--open]` | 仅返回浏览器办理指引，不创建订单；event/method/open在当前入口不执行支付或打开动作。 |
| `payment qr <orderId> [--open]` | 不生成或打开新二维码；原订单另用payment status核验，open在此不执行。 |
