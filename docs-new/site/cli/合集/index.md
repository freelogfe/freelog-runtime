# 合集使用教程

::: info CLI 同步文档
本页自动同步自 CLI 仓库使用手册。先核对已安装版本与本页适用范围；Node.js 22.14+ 是 CLI 自身要求，不是运行时对子应用的要求。来源、发布状态及已知限制见[版本说明](/about)。
:::


合集用来组织**你自己已经上架的线上单资源**。它适合把一组视频、图片、文章等资源整理成一个独立展示和授权的整体。你可以先创建空合集，完善属性、可选配置和直接依赖，再决定何时添加单品；建壳和只发表单不要求事先有单品。合集不是本地文件夹上传器，也不会替你把一批素材自动发行成单资源。

使用合集前，按[安装与AI代办](../00-版本选择与AI代办.md)准备 CLI 和工程目录；Node.js 最低为 **22.14.0**。在该目录确认已登录正确 dev 账号；未登录时再执行，已有可用登录则跳过：

```powershell
freelog-cli login --cwd . --env dev
```

操作前先确认当前工程已经登录正确账号和环境。不同任务的内容前置分别是：

| 任务 | 内容前置 |
|---|---|
| 创建合集、编辑/发布表单、维护直接依赖 | 不要求已有目录单品；直接依赖目标仍须满足依赖规则。 |

## 三类改动别混在一起

合集命令会修改三类不同事实：

| 事实 | 相关命令 | 什么时候线上可见 |
|---|---|---|
| 服务端目录草稿 | `collection item add/rename/move/sort/remove` | 运行 `collection publish` 合并目录后 |
| 本地表单操作稿 | `collection form/display/dep` | 运行 `collection publish` 提交表单后 |
| 线上即时信息 | `collection update`、`collect-rules`、`policy`、`online/offline` | 命令成功并读回后立即生效 |

Console 的表单草稿和 CLI 的本地表单操作稿不是同一个东西。CLI 不读取、不合并、不覆盖 Console 表单草稿；`collection form show` 只显示本地待发布表单，不是线上状态查询。

## 怎么选择合集

合集命令里的 `--resource` 只选择目标合集：

```text
--resource id:<合集ID>
--resource name:<username/name>
--resource file:N.json
```

推荐脚本和文档都使用 `id:<合集ID>`。标题会变、可重复，不能作为选择器。合集选择器不接受 `artifact:`；那是单资源产物路径相关用法。

## 当前边界

- 本教程覆盖创建/绑定合集、目录草稿、资料、收录规则、本地表单、直接依赖、合集策略、发布、上下架、日志和授权方合约查询。
- 已有目录单品用collection item auth status查看授权，auth resolve应用已有上游合同；缺合同去浏览器按合集身份办理，CLI本期不新签、不付款、不发布目录，见[单品管理](./02-发行后管理与边界.md#目录单品-服务端目录草稿)。
- RSS、批量发行、从本地文件夹自动生成合集不在范围；所有新支付到网页办理，旧订单只读见[支付说明](../授权与支付/支付与恢复.md)。
- `collection publish resume`默认只读，不重发。显式`--apply --yes`仅按完整证据收尾，变稿保留；已拒绝且旧基线未变时只清记录留稿。不是其它写命令的通用恢复入口，见[恢复说明](./02-发行后管理与边界.md#发布、未知结果和基线变化)。

## AI 或脚本读取结果

按具体命令读取成功 JSON：策略模板、日志/合约保留各自协议；`collection item list --json` 返回目录草稿单品数组，空态为 `[]`；`collection dep rm --json` 返回移除 ID 和仅本地保存回执，不撤销合同。其它命令查看相应说明，不从共用参数推断全部成功输出结构。

本目录会随 CLI 包发布。安装后运行 `freelog-cli --help`，按帮助里显示的本机手册路径打开 `合集/README.md` 即可。
