# Freelog CLI 使用手册

::: info CLI 同步文档
本页自动同步自 CLI 仓库使用手册。先核对已安装版本与本页适用范围；Node.js 22.14+ 是 CLI 自身要求，不是运行时对子应用的要求。来源、发布状态及已知限制见[版本说明](/about)。
:::


本手册面向 **0.6.0 及后续兼容版本**，其中依赖签约、市场与节点展品、存储管理及发行导入、展品版本管理等新增能力不包含在旧 npm 0.5.9 中。版本要求不表示该包已经发布；正式包可用后通过 npm 安装，发布前使用维护者提供的固定候选包。开始前先读[00 · 版本选择与 AI 代办](./00-版本选择与AI代办.md)，确认包来源与任务需要的命令。

先选择你要完成的任务，不需要从头读完所有文档。单资源与合集教程分开：主题、插件、图片、视频都是单资源；合集组织的是你本人线上已上架的单资源。

## 0.6.0 开发阶段发行范围

本版按开发阶段交付。完整命令组合、Console双向保存/读回及Windows/macOS/Linux安装矩阵尚未全部完成验证，不能据此认定所有场景或平台都已通过。

- 部分合集策略模板仍可能由编译服务返回stateMachine错误；保留模板ID反馈维护者，不把编译失败当添加成功。
- CLI暂不支付；合同要求付款时需到网页以正确主体完成履约，签约或添加展品不等于已获授权。
- Windows交互密码输入的Ctrl+C退出仍有未解决场景。自动化登录可用`login --password-stdin`；取消后先确认登录进程已退出，再开始新的操作。
- 当前没有主题激活/切换及展品简介、标签、自定义信息编辑入口；支付、RSS等未实现能力不会因本版发行而自动支持。

以下修正需要0.6.1或后续兼容版本，npm0.6.0不包含。若正式包尚不可获得，请使用维护者提供的固定候选包，不用旧包验证这些规则：

| 操作 | 本轮修正及详细说明 |
|---|---|
| 准备或提交版本文件 | 按当前资源类型校验来源、大小和文件占用；失败保留稿，提交前复验，见[版本工作稿](./06-版本工作稿.md) |
| 上传存储文件 | 提前检查200MiB上限，按Console规则规范化对象名并检查最终名长度，见[存储手册](./存储空间/index.md#_4-可选-上传及管理线上文件) |
| 从存储导入版本信息 | 依赖按ID合并并更新范围；属性按当前类型转换，可选配置按组选替换；预览确认后一次写稿，见[元数据导入](./存储空间/index.md#_2-明确导入对象的元数据) |

写入前先确认目标与字段：标题是可变展示信息，不是资源身份；仅知道标题时先到市场确认完整授权标识或 ID。0.6.0+ 可用 `market search <关键词> --env dev` 查找，再用 `market show <资源ID> --env dev` 核对；旧包没有该命令时先按版本指南取得支持的包，或改用 Console 市场。关键词搜索结果不等于唯一身份。简介属于listing，版本说明/合集表单描述是不同字段。填写前核对[表单限制](./06-版本工作稿.md)与[资料限制](./08-资源管理.md)，不要让AI猜可选配置是否支持或自动截断超限内容。

## 阅读约定

- CLI 最低要求 **Node.js 22.14.0**，请使用受支持的Node22或24 LTS；Node20及更旧版本不再支持。安装命令见 [01](./01-快速上手.md#_1-安装与登录)。运行 `freelog-cli --help` 可以找到安装包内的手册路径。
- 示例显式使用 `--env dev`。也支持 test；当前不开放 prod 写操作，不要省略环境后碰运气。
- 除主题模板教程明确使用 `--cwd` 外，示例都在自己的工程目录执行；相对文件路径以工程为准。
- 尖括号中的内容是占位符，先替换成真实值再执行。资源创建成功后，用返回的 ID 替换后续的 `<资源ID>`。
- 人工交互教程需要能输入和选择的终端；AI、CI 或脚本使用明确参数的非交互路径。密码不要写进参数、脚本或文档。
- 不重复登录已登录的工程；有账号或环境问题先看 [02 · 环境与凭据](./02-环境与凭据.md)。
- 每一步成功后才继续；失败、取消或结果未知时停止写操作，按[故障恢复](./09-常见情况与报错.md)核实。PowerShell 不会自动因外部命令失败而停止，自动化使用[失败即停的脚本模板](./11-命令参考.md#脚本最小安全模板)。
- 覆盖工作稿前先查看并保存需要保留的修改；导出到文件也要检查同名文件。成功提示和只读查询只证明它们明确展示的字段，不代表所有线上内容都已核验。

## 多资源工程：先选身份，再给产物

同一目录可管理多份独立单资源。目标操作优先用 `--resource id:<资源ID>` 指定身份；`--artifact <路径>` 指定本次使用的文件或构建目录，两者不是同一用途。完整选择规则见[命令参考](./11-命令参考.md#公共资源匹配参数)。

0.6.0+ 添加单资源或合集直接依赖时，先以当前资源或合集身份核验合同；缺少时选择策略并确认签约，再写依赖稿。提交版本或合集快照时也核验直接依赖合同。节点展品签约以节点为乙方，不以个人合同替代；合集单品上游合同仍按[合集教程](./合集/01-首次发行与发布.md#_2-添加线上单品)到网页处理。

**当前 CLI 暂不支持支付。需要支付才能获得授权时，未完成支付就无法获得授权。**待支付合同可能足以继续声明依赖，但不代表资源能够被访问；应到网页以相应签约主体完成支付或其它履约。正式完整能力与 Console 对齐是后续目标，不表示当前已经实现。

批量发行、RSS、手写策略语言提交、session 或 studio 多账号模式仍不在当前范围。
