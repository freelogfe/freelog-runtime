先分清本次操作的对象：

| 对象 | 含义 |
|---|---|
| 工程目录 | 你放本地文件或项目的文件夹；CLI在这里保存身份和未提交内容 |
| 资源 / 版本 | 作者发行的作品；版本是该作品一次已提交的文件、属性、配置与依赖 |
| 工作稿 | 下一次发行前可继续编辑的本地内容，尚未成为线上版本 |
| 作者合集 | 作者发行的资源集合，收录本人线上已上架的单资源 |
| 节点 / 展品 | 节点是展示和使用资源的空间；资源签约到节点后成为展品 |

作者合集与节点自建展品合集用途不同，分别进入上表的专用教程。

## 阅读约定

- 首次安装要求 **Node.js 22.14.0或更高版本**，使用受支持的Node22或24 LTS。安装、包来源和AI分工统一见[00](./00-版本选择与AI代办.md)。
- 示例使用 `--env dev`；也支持test。当前prod的平台读写调用均被拦截。登录与环境规则见[02](./02-环境与凭据.md)。
- 在自己的工程目录执行命令；指定 `--cwd <目录>` 时，相对文件路径以该目录为准。`<资源ID>`等尖括号内容先换成真实值。
- 按教程逐步操作，在选择、编辑、构建或确认处停下来；不同分支的代码块不是一份可连续执行的脚本。
- 每一步明确成功才继续。失败、取消或结果未知时先看[故障恢复](./09-常见情况与报错.md)，不要盲目重复写入。

## 多资源工程：先选身份，再给产物

`--resource id:<资源ID>`选择要操作的资源；`--artifact <路径>`指定本次文件或构建目录。同一目录可管理多份独立资源，操作时显式给出ID，完整规则见[公共资源匹配参数](./11-命令参考.md#公共资源匹配参数)。标题可以修改、可以重复，不能当作唯一身份。

寻找公开市场资源用 `market search <关键词> --env dev`，再用 `market show <资源ID> --env dev`核对。寻找自己的下架或非公开资源，先查本地 `resource list`，或到Console取得精确ID后查询；市场没有搜索结果不等于资源不存在。

## 当前限制

依赖可先存入工作稿，发行前仍要核对以当前资源或合集为被授权方的生效合同。当前依赖签约、已有展品补签、合集单品上游补签和新支付到浏览器办理，具体步骤见[授权与支付](./授权与支付/index.md)及[支付说明](./授权与支付/支付与恢复.md)。声明保存、已签约、已支付和实际访问授权分别核对。

节点新展品签约由CLI内联auth-cli完成，无需另装或重新登录；用户仍只使用 `freelog-cli` 命令，操作见[签约成展品](./节点与展品/index.md#_2-签约成展品)。

批量发行、RSS、手写策略语言提交、微信登录、session和studio多账号模式当前不提供。部分合集策略模板可能被编译服务拒绝，失败不代表已添加。Windows密码输入时Ctrl+C仍有进程未退出的已知场景，取消后确认进程结束再继续，详见[登录说明](./02-环境与凭据.md#人工登录与切换)。
