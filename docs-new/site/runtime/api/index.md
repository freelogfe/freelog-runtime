# 运行时 API

这些 API 面向 Freelog 节点内的主题与插件，通过运行时提供的 `freelogApp` 调用。资源发行、节点管理、CLI 登录 不属于本目录能力。

先读[调用与返回约定](./base.md)，再按任务选择：

| 任务 | 文档 |
| --- | --- |
| 节点信息、自身属性依赖、挂载与组件通信 | [主题与插件](./widget.md) |
| 查询展品、授权状态、展品与依赖文件 | [展品](./exhibit.md) |
| 合集展品单品、单品授权与依赖文件 | [合集展品](./collection.md) |
| 当前消费者、登录、账号变化与用户数据 | [用户](./user.md) |
| 消费者授权交互 | [授权处理](./auth.md) |
| 分享链接与微信/QQ 分享 | [分享](./share.md) |
| 业务错误响应 | [状态码](./code.md) |

## 对象与权限边界

展品使用 `exhibitId`；合集单品还需 `itemId`；依赖使用顶层展品 ID 与链路 `nid`。资源 ID、展品 ID、单品 ID、链路 ID 不能互换。顶层展品可以是主题或独立插件展品。

查到元信息、已有合约、生成文件 URL、组件挂载成功，分别不等于当前文件访问获授权。消费者授权交互不能代替作者依赖签约或节点接入授权。

## 依据与限制

正文迁自原 API 文档，并核对当前 `freelogApp.ts`、`widgetUtils.ts`、`widget.ts`、`user.ts`、API 模块与请求处理器。JSON 示例说明字段，不保证服务端每次返回所有字段；不补写未经查证的后端行为。

依赖插件 `getSelfProperty()` 当前有提取与缓存实现限制，详见[方法说明](./widget.md#getselfproperty)。此次只修改文档。
