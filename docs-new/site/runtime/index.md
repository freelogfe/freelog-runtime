# 运行时开发指南

Freelog 节点运行时是在浏览器中打开节点时加载的主应用。它启动当前启用的主题，并为主题及其挂载的插件提供展品、依赖和授权上下文。主题决定节点页面如何组织内容，插件由主题或父插件挂载。两者都以包含入口 HTML 和静态文件的浏览器端构建产物接入。

## 从当前已有的条件开始

| 你要做什么 | 从哪里开始 | 完成时看到什么 |
| --- | --- | --- |
| 准备可开发的节点 | [准备真实节点和基础主题](/runtime/node-setup) | 节点地址可访问，主题已启用，展示版本明确 |
| 第一次在节点运行主题 | [从真实节点运行第一个主题](/runtime/quickstart) | 节点页面显示本地主题，Network 可见本地入口 |
| 第一次做插件 | [建立首次真实挂载](/runtime/development#一个全新插件从哪里开始) | 已发行插件在节点页面的预期位置出现 |
| 调试页面中已有的插件 | [替换已挂载插件的代码](/runtime/development#调试已经有挂载位置的插件) | 目标实例从本地入口加载，原位置能看到修改 |
| 开发或加载前端软件库 | [前端软件库指南](/library/) | 主题或插件能从真实依赖路径加载库 |
| 发行新版本并检查效果 | [发行主题或插件并验证上线](/runtime/release) | 精确读回线上版本、确认节点实际采用的版本，并在正式地址验证 |

- [对象和身份](/runtime/architecture)说明资源、展品、依赖节点 `nid` 和挂载实例分别从哪里取得。
- [兼容性与版本](/runtime/compatibility)说明如何填运行时目标和构建工具，如何从资源版本、启用主题及节点入口核对生效结果。
- [运行时 API](/runtime/api/)提供实际挂载、读取展品和依赖、检查授权等接口参考。

- [问题排查](/runtime/troubleshooting)按本地入口、运行时初始化、挂载、版本和授权定位失败。
