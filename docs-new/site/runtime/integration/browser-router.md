# 浏览器路由模式

主题与插件可以在自身沙箱内运行浏览器路由库。先按[应用路由](./router.md#路由模式)选择 `search`、`pure` 或 `state`，再在对应模式下检查刷新、返回以及重新挂载后的页面。希望复制节点地址后可定位子应用页面时，选择 `search`。

## 路由类型约束

应用自己的页面路由由所选的路由库声明。父应用控制已挂载子插件的页面时，使用 `freelogApp.router.push({ name, path })`，`name` 来自挂载控制器。应用之间也可通过[数据通信](./data.md)提出导航请求。

## 基础路由

应用内部由自身路由库管理页面。节点地址和各插件的路由同步通过 [挂载 API](/runtime/api/widget#renderwidgetoptions-说明)选择，应用应保留地址中已有的节点及其他插件的路由参数。
