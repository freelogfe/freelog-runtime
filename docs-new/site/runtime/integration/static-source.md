# 脚本与样式处理

运行时读取主题或插件的入口 HTML，并按应用的入口地址补全资源引用。构建时检查脚本、样式和图片的实际产物路径。Vite 工程可使用[相对构建路径](/reference/frameworks/vite#正式产物)。

## 资源共享

运行时按补全后的 URL 缓存外部脚本和样式。业务需要共享代码时，可声明并加载[前端库](/library/)，通过实际依赖链解析版本和授权。

## 资源过滤

### 配置 `exclude` 属性

当前 HTML 提取器会过滤带 `exclude` 属性的 `link`、`script` 和 `style`。例如，当工程同一入口还为独立预览附带一段脚本，可明确标记它在嵌入时应跳过：

```html
<script src="./standalone-preview.js" exclude></script>
```

检查正式构建后入口仍保留该属性，并在真实节点的 Network 面板核对实际请求。所有节点内必需的脚本或样式都应能正常加载。
