# 文档版本、来源与迁移状态

新版文档工作目录为运行时仓库 `docs-new`；旧 `packages/docs` 没有因本次重构被替换或修改。当前尚未部署，不声称新站已在线。

## 三类版本分别注明

| 范围 | 当前依据 | 说明 |
|---|---|---|
| 运行时主应用 | 本地源码 `2fa5f83f` | 基于本地维护的 MicroApp 改造版，不能直接将上游最新版行为当现状 |
| 类型/接入包 | 仓库 `freelog-runtime` 5.0.7 | 主题/插件的 SDK 兼容范围见版本页，不等于 Node.js 版本 |
| CLI 手册 | CLI源手册，本次核对已发布npm0.6.1包内正文 | npm0.6.1已发布并完成下载/安装核验；本版Console浏览器由用户延期，历史完整覆盖与三平台未验仍保留，适用范围见[手册首页](/cli/) |

精确 CLI 来源见[同步记录](/source-lock.json)，包含原始与生成正文摘要。同步时间不作为发布批准；`dirty` 表示文档或包元数据含未提交改动。

CLI正文通过脚本从唯一源手册同步，不是在站点手改的副本。2026-10-30曾逐页核对npm0.6.0下载包；2026-11-02重新同步后已包含0.6.1的文件来源/大小/占用校验、存储元数据导入及合集完结规则修正，并与已下载的npm0.6.1包内19份手册逐字节核对；这些不包含在npm0.6.0中。`source-lock.json`记录本次源提交、dirty标记及逐页摘要，`channel: development`不代表npm发行。后续源手册再变化时须重新核对，不能仅凭相同版本号认定正文与npm包一致。

CLI 0.6.0为获准的开发阶段版本：完整命令/业务覆盖证明、Console双向浏览器、三平台完整验证尚未闭合，固定合集策略模板仍有后端编译失败，Windows密码取消有既定单例隔离。已完成的专项测试不等于全部场景通过。当前CLI暂不支付；需支付才能授权时，未完成支付无法取得相应授权。请按[版本选择](/cli/00-版本选择与AI代办)和[错误处理](/cli/09-常见情况与报错)操作，不把发行或签约成功当真实访问已获授权。

## 迁移处理

- 核心入门、架构、版本、开发与发行重新按任务编写，不靠截图提供关键字段。
- API 参考保留完整接口，修正已确认的方法名、示例与返回层级问题；没有对应真实环境逐接口执行，不能把文档修正当成全部 SDK 通过测试。
- 框架和库示例保留为进阶参考，适用技术版本与示例文件分别说明，不把历史工具链当平台限制。
- CLI 页面自动同步，禁止在站点手工改写命令。五视角复查后已回源修正“依赖只声明、不签约”的旧说明、错误恢复指引及AI示例，并删除生成侧旧段落特判；当前CLI暂不执行支付的边界在源手册中明确。

## 已知限制

1. 当前运行时没有通用的资源 ID 直接查询入口；本地新增依赖不自动产生真实展品依赖路径。
2. 未发行依赖的模拟方案已撤下；不提供直接下载的替代路径。
3. 源码 `getSelfProperty` 的依赖分支存在未等待请求的实现问题，新站标注限制，不借整理文档修运行时。
4. dev/测试站点部署对应关系尚未确认。SDK 网络调用、支付与授权真实性需另行实测。

## 新站维护

正文、图片和代码示例都要可独立阅读。多阶段步骤先给主线，再写前提、执行和结果；图表配文字，示例配上下文和返回层级。

新站构建拒绝失效页面链接，生成的 CLI 内容有摘要校验。网站能构建、能搜索，不代表文档中的所有业务流程已在平台验证。
