# Agent 阅读与操作约定

本页面向代办平台任务的 Agent，不限于主题/插件开发。用户可以让你发行图片、管理合集或存储、运营节点展品，也可以开发应用。先用[人与AI协作入口](/start)明确目标和已有条件；你负责检查与执行，用户负责业务选择、本人认证/支付和结果确认。

## 从这里建立上下文

1. [平台对象](/platform/overview)：分清作者资源、资源版本、作者合集、节点和展品，以及各自的签约主体。
2. [任务目录](/platform/tasks)：按本次业务目标选择下面的阅读路径。
3. [CLI版本选择](/cli/00-版本选择与AI代办)与[文档状态](/about)：区分已安装能力、开发分支修正和未实现功能。

## 按任务读取，不把所有任务都当成应用开发

| 用户目标 | 需要阅读 | 结果核验 |
|---|---|---|
| 发行图片、视频、音频等普通文件 | [首次发行](/cli/01-快速上手)、[版本表单](/cli/06-版本工作稿)、[作者策略](/cli/07-单资源授权策略) | 版本文件及表单、策略和资源上架分别读回 |
| 更新或管理已有单资源 | [绑定与更新](/cli/04-日常路径)、[资源管理](/cli/08-资源管理) | 保留当前稿，核验所选资源、新版本或资料；不自动更新节点展品 |
| 发行或管理作者合集 | [合集教程](/cli/合集/) | 核验本人线上单品、目录、表单、策略及状态；不当成文件夹批量发行 |
| 管理线上存储或从存储发行 | [存储教程](/cli/存储空间/) | 区分线上对象、发行来源及显式导入的元数据，不维护本地空间副本 |
| 搜索资源、创建节点或管理节点展品 | [节点与展品业务](/platform/nodes-and-exhibits)、[操作教程](/cli/节点与展品/) | 节点归属、展品来源/版本、策略和上下架分别核验；创建节点先提醒额度并取得具体确认 |
| 开发或调试主题、插件、前端库 | [运行时结构](/runtime/architecture)、[版本边界](/runtime/compatibility)，再读[开发调试](/runtime/development)或[库开发](/library/) | 区分本地代码替换、正式版本、实际挂载与真实内容访问 |
| 在应用中展示内容或排查访问授权 | [授权边界](/platform/authorization)、[SDK参考](/runtime/api/)、[排查](/runtime/troubleshooting) | 核对展品/单品/依赖上下文及真实授权，不用资源列表可见代替文件可访问 |

普通文件发行、存储管理、合集或展品运营不要求先学习运行时接入、启动本地应用或创建节点。只有任务涉及节点页面中的应用开发或SDK调用时，才继续阅读运行时章节。首次发行、新版本、资料修改及上下架也不是一套必须全部重走的流程。

平台业务与执行入口的对应关系在[任务目录](/platform/tasks)。先判断用户是在作者发行、节点运营还是访问者消费阶段，再选命令或SDK，不把CLI和运行时当成两套割裂的业务。本站应独立提供任务所需知识，不能把关键步骤推给另一套官方帮助。

执行前先按[CLI版本选择](/cli/00-版本选择与AI代办)核对已安装能力和可获得的候选。没有所需候选，不因为文档列了命令就反复尝试正式包；说明阻塞，并按文档选择Console替代路径。

## 不使用浏览器时

- [llms.txt](/llms.txt)：页面索引与建议阅读顺序。
- [llms-full.txt](/llms-full.txt)：全文，适合下载后检索；内容多时优先按页读取。
- Markdown 正文：从 `llms.txt` 中取得对应的 `/markdown/…​.md` 地址，与页面正文同源，不必解析页面 HTML。
- [来源记录](/source-lock.json)：CLI 版本、提交、是否含未提交文档、逐页摘要。

这些入口帮助发现正文，不会授权 Agent 执行远端写入，不包含登录态或账号凭据。

## 调用与验证

CLI 优先使用 JSON 输出和明确资源/环境；先看本地状态，再编辑。没有工作稿不能把线上版本当成本地稿。远端结果未知时先查，不重复发行。

运行时 API 先核对作用域、参数、同步/异步和返回信封。当前实时查询与缓存查询不保证相同返回层级，不能根据函数名称猜。示例占位符必须替换，不把 `<资源ID>` 当真实值。

截图不是字段协议，页面出现“未来”“未实现”“待核验”不能据此生成接口。资源信息查询、真实文件访问和插件挂载分别验证。

当前CLI暂不执行支付。策略要求先支付才能授权时，未支付无法取得相应授权；不得把签约成功、待支付合同、依赖声明或版本发行说成支付/授权完成。具体主体见[支付边界](/platform/authorization)。

## 当前文档边界

CLI正文自动同步自CLI源手册，本次已核对已发布npm0.6.1包内手册；npm0.6.0不包含本轮修正。来源、dirty标记和摘要见[source-lock.json](/source-lock.json)，各项适用版本及保留限制见[文档状态](/about)。运行时内容按仓库源码核对，尚未证明线上部署对应当前提交，不能因此承诺所有SDK调用已在该环境实测。
