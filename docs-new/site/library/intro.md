# 库只能作为主题或插件的依赖使用

## 1. 库在本平台是什么、能做什么？

前端库为主题或插件提供 JavaScript 工具、React 或 Vue 组件，以及可选的 CSS。库的 JS 入口使用 UMD，导出挂在约定的命名空间下。运行时把库的脚本和样式加载到引入者的应用中，库可以影响引入者的 DOM 和样式。

## 2. 适用场景

多个应用使用同一组函数、组件或样式时，可以把公共部分构建为前端库。需要独立页面、虚拟路由或挂载生命周期的应用，按[主题与插件架构](/runtime/architecture)接入。

## 3. 产物

发行包根目录包含 `meta.json`、UMD 入口及该库使用的其他文件。 `meta.json` 描述命名空间和产物。授权、版本范围及选中的库版本由应用依赖关系决定。文件结构和工具示例见[构建约定](/library/guide)。
