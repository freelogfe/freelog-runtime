## 技术和生成内容

- 按用户选择固定 VitePress `2.0.0-alpha.21`，不使用浮动 `next`；当前包带alpha标识，升级时单独验收。
- 新站独立 package.json / package-lock.json，不改运行时 workspace 或旧站依赖。
- CLI 文件以源稿为唯一编辑来源；同步适配 README→index 和渲染器锚点，保持代码块原文。
- CLI源中旧“仅声明不签约”、错误参数恢复等说明已在本轮回源修正；同步器不再对旧规则特殊包装，只适配链接与来源提示。
- llms、纯 Markdown、来源JSON和清单由同一正文生成；删除页面后清除失效的导出副本。
- Mermaid按需加载，图配文字与可展开源码；图表库体积较大，构建有大chunk提醒，不把它隐藏成“没有告警”。

## 使用与核验

```sh
npm ci
npm run verify
npm run preview
```

上面命令在 `docs-new` 执行。`verify` 包括生成器回归、CLI同步、页面/资源/锚点/摘要检查和静态构建。子路径用 `DOCS_BASE` 控制，具体赋值遵循当前终端；例如PowerShell：

```powershell
$env:DOCS_BASE = '/preview/'
npm run build
Remove-Item Env:DOCS_BASE
```

文档构建与浏览器检查只证明文档可用，不代替实际资源发行、授权、文件访问和节点联调。运行时依赖分支 getter 已知限制及部署来源未核实项，在站点 `/about` 如实记录。

## 切换旧站前

1. 确认CLI发布/候选版本，重新同步并核对来源锁；不能把0.5.9包元数据当新功能已发布。
2. 验证部署目录、HTTPS、静态文件和旧URL重定向，保留旧站回退目录。
3. 确认默认/子路径下的搜索、Markdown下载、图表与代码复制。
4. 只在获得部署授权后替换站点；当前仅提供本地预览。
